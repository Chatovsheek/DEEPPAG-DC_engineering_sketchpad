# DEEPPAG-DC_инженерный эскизник
**DEEPPAG-DC engineering sketchpad**

**Лёгкий чертёжный инструмент в браузере.** 2D-черчение с размерами по ГОСТ, рамкой и штампом, привязкой к геометрии. Один HTML-файл, интернет не нужен.

## 🚀 Быстрый старт
1. Открыть файл в Chrome, Edge или Firefox
2. Выбрать инструмент и рисовать
3. Сохранить: PDF, PNG, SVG или JSON (кнопка «💾 Сохранить»)

## 🛠️ Инструменты и горячие клавиши
| Клавиша | Инструмент | Действие |
|---|---|---|
| `1` | 📏 Линия | клик-начало, клик-конец |
| `2` | ⬛ Прямоугольник | два клика по диагонали |
| `3` | ⚪ Окружность | центр, радиус |
| `4` | 📏 Размер | **три клика**: две точки, затем положение размерной линии |
| `5` | 🖱️ Выбрать | выделить и двигать; `Ctrl+клик` параметры; `Shift+клик` удалить; `Delete` удалить выделенное |
| `6` | 🔤 Текст | однострочный |
| `7` | 🧽 Ластик | рисует цветом фона |
| `Ctrl+Z` | | отмена (в т.ч. перемещений и правок параметров) |
| `Esc` | | отмена постановки размера |
| `Alt+ЛКМ` / колёсико-кнопка | | панорамирование |
| Колёсико | | зум |

## 📐 Размеры
- **Линейный размер:** выносные линии, стрелки, надпись вдоль размерной линии. Положение линии задаётся третьим кликом.
- **Окружность** (авторежим): диаметр ⌀ со стрелками под углом 45° и, по галочке, длина окружности `L=`.
- **Линия** (авторежим): длина над линией; галочка «Задать длину» скрывает её.
- **Ручной режим:** размеры линий, прямоугольников и окружностей не показываются; размерная линия показывается всегда.

## 🎮 Режимы
- 🤖 **Авторежим:** после рисования окно с параметрами (длина, угол, тип линии, толщина)
- ✏️ **Ручной режим:** фигура появляется сразу

## ⚠️ Авто- и ручной режим: не смешивать
Размеры авторежима не хранятся в чертеже, а показываются у **всех** фигур, пока включён 🤖 Авторежим. Если часть размеров поставлена вручную инструментом «Размер»,
 а потом включён авторежим, надписи автоматических размеров ложатся поверх ручных, и получается каша.

Выбирайте один способ на весь чертёж:
- **Авторежим:** размеры сразу у всех фигур. Лишний размер у линии убирается галочкой «Задать длину».
- **Ручной режим + инструмент «Размер»:** размеры ставятся только там, где нужно, по ГОСТ.
- ** Гибридный способ - ( самый удобный ) ** Для удобства в автоматическом режиме чертите все фигуры или линии, так вы точно создадите чертеж нужных размеров,
                                             потом переходите в ручной режим и нажимаете кнопку размер. Автоматические размеры скрываются.
											 Выставляете размеры и сохраняете. Такой трюк можно проделывать столько раз, сколько неоюходимо.

## 📐 Типы линий
Сплошная, штриховая, штрих-пунктирная, пунктирная; толщина 1–6 px.
## 🎨 Фон поля
Кнопка «Белый фон / Тёмный фон». На белом всё рисуется чёрным (цвета в данных не меняются), палитра блокируется. На тёмном доступна полная палитра.

## 📋 Рамка по ГОСТ 2.104
- Список: Нет / A4 (вертикально) / A3 (горизонтально)
- Масштаб: «Авто» (из ряда ГОСТ 2.302 по размеру чертежа) или вручную
- Рамка центрируется по чертежу; поля: слева 20 мм, остальные 5 мм
- «✏️ Штамп»: основная надпись (форма 1, 185×55 мм): обозначение, наименование, организация, литера, масса, лист/листов, подписи и даты. Масштаб подставляется сам.
- Размеры граф штампа проверьте по требованиям вашей организации.

## 💾 Сохранение (встроенное, без внешних модулей)
| Формат | Примечание |
|---|---|
| PDF | картинка высокого разрешения (JPEG); с рамкой страница равна листу A4/A3, без рамки A4/A3 с полями 10 мм |
| PNG | весь чертёж (или лист с рамкой), размер 2000/4000/8000 px |
| SVG | вектор, со всеми размерами и рамкой |
| JSON | проект: фигуры, поле, сетка, тема, рамка, штамп |

Опции: сетка (PNG/PDF), «белый фон, чёрные линии» для печати.

## 🖥️ Управление
Поле в метрах (его граница рисуется пунктиром), шаг сетки 10–100 мм, зум кнопками `+`/`−`/`⟳`.

## ⚙️ Совместимость
Chrome 90+, Edge 90+, Firefox 88+. Один файл, можно носить на флешке. Значок (циркуль и линейка) виден во вкладке браузера; на рабочий стол его можно вынести
 через «Создать ярлык» в браузере.

## ❓ Частые вопросы
- **Как поставить размер между точками?** Инструмент «Размер»: клик, клик, клик (третий задаёт отступ). `Esc` отменяет.
- **Как сделать линию без размера?** В авторежиме снять галочку «Задать длину».
- **Как изменить размер нарисованной линии?** «Выбрать» + `Ctrl+клик`.
- **Ластик оставляет след?** Он красит цветом текущего фона; на белом поле работает так же.
